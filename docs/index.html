iPage Quick GR and NG

This Firefox extension adds Goodreads statistics and direct Goodreads and NetGalley book links above the Notes field on individual Ingram iPage product pages. It puts the information I use when evaluating books in one place, without changing how iPage saves my work.

How to Install the iPage Quick GR and NG Extension

  1. Use Firefox 142 or newer, then select the purple installation link below.
  2. If Firefox prompts you to add the extension, review the permissions and follow the prompts. If the .xpi file downloads instead, open about:addons in Firefox, select the gear menu, choose Install Add-on From File, and select the downloaded file.
  3. Open Ingram iPage and navigate to an individual book's Product Detail page to start using the extension.

Install version 1.0.6 for Firefox

Fallback: signed version 1.0.5

Firefox checks for newer signed releases according to its add-on update settings, so you do not need to reinstall the extension after each update.

How to Use the Extension

  1. Open a book from a selection list in Ingram iPage. The extension works on the individual Product Detail page, not the multi-book cart or search results list.
  2. Look above Notes for the Goodreads information and links to the book's Goodreads and NetGalley pages. The extension opens a background tab for each source and leaves those tabs available if you want to check the matches yourself.
  3. Select Refresh if you want to run the book lookup again, or Close GR/NG tabs to close the source tabs opened by the extension.
  4. When you're ready to move on, use iPage's usual Update control. The extension closes its source tabs and allows iPage's normal save process to continue. When iPage provides a next-book link, Update takes you to that book after saving.

How Book Information Is Found and Displayed

Goodreads information

The panel displays a Goodreads rating, the number of ratings and reviews, and a want-to-read count when those values can be found. Ratings below 3.0 are marked NR:. Unavailable statistics are generally shown with a dash; a missing want-to-read total on a matched book may display as 0wtr.

Matching books

The extension looks for the right Goodreads record using the book's ISBN and title, with additional title-and-author checks when necessary. These include fallbacks for certain edition labels, subtitles, and trailing parenthetical information. It also looks for a matching NetGalley page. If no reliable match is available, the extension does not invent one.

Matching sometimes fails when book titles include subtitles or parenthetical information. If a book with a subtitle or parenthetical shows blank, unusually low, or zero Goodreads counts, double-check the results by searching Goodreads manually using only the main title.

Source tabs and iPage

The extension reuses the Goodreads and NetGalley tabs it opens while checking a book. It does not read or edit the contents of Notes, submit a separate iPage save request, or replace iPage's own validation. You can inspect the source tabs, close them with the extension's control, or let Update close them as you work through your list.

Privacy and permissions

The extension reads the current book's title, author, and ISBN for its lookups and caches retrieved results in Firefox's local extension storage. It does not send information to an AI service or include analytics or advertising code. See the privacy information for details about website requests, optional private-window behavior, and extension permissions.
